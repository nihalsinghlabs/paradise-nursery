# Paradise Nursery

Paradise Nursery is an online plant shop built with React, Redux Toolkit, and React Router.

## Features
- Landing page with the company name and a "Get Started" button
- Product listing with houseplants grouped into three categories
- "Add to Cart" buttons that disable after a plant is added
- Navbar with Home, Plants, and Cart links, plus a dynamic cart icon count
- Shopping cart page with quantity controls, per-item and total costs, delete, checkout ("Coming Soon"), and continue shopping
- About Us page

## Getting Started
1. Run `npm install`
2. Run `npm run dev`
3. Open the local address shown in the terminal
